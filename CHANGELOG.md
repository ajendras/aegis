## [0.1.0] - 2026-11-04

### Added

- Live Dashboard — Real-time device grid showing status, platform, last seen and battery.
- E2E Encryption — Per-device libsodium keys protect every command and response.
- Agent Protocol — Unified JSON-over-WebSocket protocol with platform-specific handlers.
- Instant Commands — Shell, screenshot, file push/pull and app install on any connected device.
- AI Assistant — Suggests multi-step automation scripts from plain English goals.
- Audit Log — Searchable immutable log of every action with one-click replay.
- WebSocket Hub — Persistent bidirectional connections via Ratchet for low-latency control.
- Bulk Ops — Tag devices into groups and dispatch commands or automations to many at once.
- Dark UI — Polished responsive panel with smooth micro-animations and full keyboard support.
